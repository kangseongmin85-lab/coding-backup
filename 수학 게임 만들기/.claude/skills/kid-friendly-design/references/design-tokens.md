# 디자인 토큰 — 여우 선생님과 세로셈

현재 구현(`style.css`의 `:root`)과 일치하는 토큰. 변경 시 이 표와 `style.css`를 함께 갱신한다.

## 색

| 토큰 | 값 | 뜻 / 쓰임 |
|------|-----|-----------|
| `--ink` | `#2b2b3a` | 기본 글자·숫자 |
| `--ink-soft` | `#6b6b82` | 보조 글자·설명·비활성 |
| `--line` | `#ececf3` | 카드 테두리·구분선 |
| `--one` | `#2f7be8` | **일의 자리 = 파랑** |
| `--ten` | `#16a06a` | **십의 자리·10 = 초록** |
| `--hundred` | `#f0a020` | 백의 자리 = 주황 |
| `--accent` | `#ff7759` | **coral — 포인트·정답·강조** (DESIGN-cohere에서 계승) |
| `--accent-d` | `#ec5536` | coral 진한(hover/active) |
| `--sub` | `#6c5ce7` | 뺄셈 보조 강조(보라) |
| `--fox` | `#ff8a3d` | 여우 몸 색 |
| `--card` | `#ffffff` | 카드·작업판 바탕 |

바탕: 옅은 따뜻한 그라데이션(`radial #fff5ee` + `linear #fbf7ff→#eef4ff`). 차가운 단색 금지.

## 둥근 정도 (radius)

| 토큰 | 값 | 쓰임 |
|------|-----|------|
| `--r-sm` | 10px | 셀·작은 요소 |
| `--r-md` | 16px | 입력·키패드 |
| `--r-lg` | 24px | 카드·작업판 |
| `--pill` | 999px | 버튼·칩·점수 |

## 타이포 스케일

| 역할 | 크기 | 굵기 |
|------|------|------|
| 세로셈 숫자 | 3.1rem | 800 |
| 로고 | 2.3rem | 800 |
| 화면 제목 | 1.2rem | 800 |
| 말풍선 본문 | 1.08rem | 700 |
| 캡션/설명 | 0.85rem | 400~700 |

숫자는 `font-variant-numeric: tabular-nums`로 자릿수 폭 고정.

## 모션 파라미터

| 이름 | 값 | 쓰임 |
|------|-----|------|
| 등장 튐 이징 | `cubic-bezier(.2,1.5,.4,1)` | 숫자 pin, 마스코트 hop, 가르기 등장 |
| 단계 전이 | 0.3~0.5s | 블록/숫자/보조판 등장 |
| 마스코트 idle | `bob 3s ease-in-out infinite` | 살아있는 느낌 |
| 마스코트 happy | `hop .5s` (점프) | 정답·완성 |
| 별/배너 | floatUp 1.1s / banner 1.3s | 보상(희소하게) |

## 마스코트 상태(클래스)

| 클래스 | 효과 |
|--------|------|
| `.mascot` 기본 | 뜬 눈(`.eyes-open`), 옅은 미소, idle bob |
| `.mascot.mood-happy` | 웃는 눈(`.eyes-happy`)로 전환, hop 점프 |
| `.mascot.big` | 홈 화면용 큰 크기 |

여우 SVG는 `script.js`의 `FOX_SVG`에 정의, `paintFoxes()`가 `[data-fox]`에 주입, `setMood()`로 표정 전환.

## 자리값 색 매핑(중요)

세로셈·보조판에서 색은 자리/역할을 뜻한다. 깨지 말 것:
- 일·일 관련 보조수 → `--one`(파랑)
- 십·"10 만들기" 관련 → `--ten`(초록)
- 정답·결과 → `--accent`(coral)
- 받아올림 작은 1 → coral, 받아내림 빌린 작은 1 → 파랑
