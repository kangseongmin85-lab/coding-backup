# 작문 가이드

blog-writing이 `03_draft.md`를 쓸 때 따르는 문체·구조 표준.

## 블로그 톤

- 기본은 **명확하고 친근한 전문가 톤** — 독자를 가르치되 깔보지 않는다. 2인칭("여러분/당신")을 적절히 써 거리를 좁힌다.
- 전제의 톤 지정(캐주얼/격식/중립)이 있으면 그것을 우선한다. 캐주얼이면 구어·짧은 문장·가벼운 비유를, 격식이면 객관적 서술·완결된 문장을 쓴다.
- 능동태를 기본으로, 추상명사 나열보다 동사 중심으로 쓴다.
- 전문용어는 처음 등장 시 한 줄로 풀어준다(독자 수준이 일반일 때).

## 문단 길이

- 한 문단은 **2~4문장**, 한 가지 생각만 담는다. 화면에서 긴 문단은 이탈을 부른다.
- 섹션마다 소제목(`##`)을 두어 스캔 가능하게 한다.
- 필요 시 목록(불릿/번호)으로 호흡을 준다 — 단, 글 전체가 목록이 되지 않게 한다.

## 인용 표기법

- 본문에서 사실·통계를 쓸 때 문장 끝에 `[출처 N]`을 단다. N은 `02_research_outline.md`의 출처 번호와 일치시킨다.
- `[출처 미검증]` 항목을 본문에 쓸 때는 단정적 표현을 피하고("~로 알려져 있다") 그대로 `[출처 미검증]`을 유지한다 — editor가 검증 게이트에서 처리한다.
- 글 끝 "출처" 섹션에 본문에서 실제 인용한 출처만 정리한다(인용 안 한 출처는 빼고, 인용한 출처는 빠뜨리지 않는다 — 일대일).

## 제목 작성 패턴

- 타깃 키워드를 제목 앞쪽에 배치한다(SEO + 독자 인지).
- 효과적인 패턴: 숫자형("~하는 5가지 방법"), 방법형("~하는 법"), 질문형("왜 ~인가?"), 가치 약속형("~로 ~ 줄이기").
- 낚시·과장은 금지 — 본문이 제목의 약속을 지켜야 한다(editor가 정합성을 점검).
- 길이는 대략 60자 이내(검색 결과 잘림 방지).

## 도입-본문-결론 구조

- **도입:** 훅(놀라운 통계·문제·질문)으로 시작 → 글이 무엇을 줄지 한 줄로 약속. 길게 끌지 않는다(2~3문단).
- **본문:** 개요 섹션을 논리 순서대로. 각 섹션은 주장 → 근거(인용) → 예시/설명의 흐름. 섹션 간 전환 문장으로 연결한다.
- **결론:** 새 정보를 넣지 않는다. 핵심을 요약하고 독자에게 행동 제안이나 생각거리를 남긴다.

## 자기 점검

- [ ] 본문의 모든 사실 주장에 `[출처 N]` 또는 `[출처 미검증]`이 있다.
- [ ] 개요에 없는 새 주장을 지어내지 않았다.
- [ ] 제목이 본문 내용과 정합한다(약속 이행).
- [ ] 목표 분량에 수렴한다.
- [ ] 글 끝 출처 목록이 본문 인용과 일대일 대응한다.
