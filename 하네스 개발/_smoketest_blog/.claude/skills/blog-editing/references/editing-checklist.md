# 편집 체크리스트 & 반려 기준

blog-editing이 발행본을 확정하기 전에 적용하는 기준.

## 교정 항목

- **맞춤법·문법:** 오탈자, 띄어쓰기, 조사·어미 오류.
- **일관성:** 용어 표기(같은 개념을 같은 단어로), 인칭(2인칭/3인칭 혼용 금지), 시제, 숫자·단위 표기 형식, 외래어 표기.
- **문장:** 지나치게 긴 문장 분할, 중복 표현 제거, 능동태 우선.

## 구조·가독성

- 도입-본문-결론이 모두 존재하는가.
- 문단이 2~4문장으로 적절히 끊겨 있는가, 소제목으로 스캔 가능한가.
- 섹션 논리 순서와 전환이 자연스러운가.
- **제목-본문 정합:** 제목의 약속을 본문이 지키는가(낚시 아님).

## 사실 정합 검증 (핵심 게이트)

- 본문의 모든 `[출처 N]`이 `02_research_outline.md` 출처 목록에 **실재**하는가(허위 인용 없음).
- 인용된 주장이 해당 출처의 내용과 맞물리는가(출처 오용 없음).
- 출처 없는 단정적 사실 주장이 있는가 → 있으면 반려 사유.
- `[출처 미검증]` 항목 → 삭제하지 말고 발행본에서 단정 표현을 완화("~로 알려져 있다", "~로 보인다").

## 반려 기준 (blog-writer에게 1회 반려)

다음 중 하나라도 해당하면 편집 강행 대신 반려한다. 사유를 구체적으로 적는다.

- 허위 인용 또는 출처-주장 불일치가 있다(편집자가 출처를 지어낼 수 없음).
- 개요/리서치에 없는 새 사실 주장이 본문에 있다(환각 의심).
- 도입·본문·결론 중 빠진 구성요소가 있다.
- 제목이 본문과 명백히 불일치한다(낚시).
- 목표 분량을 크게 벗어나 구조가 무너졌다.

단순 교정으로 고칠 수 있는 문제(오탈자·문단 정리·표기 통일)는 **반려하지 말고 직접 고친다**. 반려는 작가의 재작성이 필요한 경우에만.

반려는 **최대 1회**. 회신받은 수정 초안이 여전히 미달이면, 가용한 부분으로 발행하되 한계를 `04_edit_notes.md`와 발행본 상단 주석에 명시한다.

## 메타 설명 작성

- **160자 이내** (검색 결과 노출 시 잘림 방지). 초과 금지.
- 글의 핵심 가치를 한두 문장으로, 타깃 키워드를 포함.
- 본문 첫 문장 복사가 아니라 검색 사용자를 위한 요약으로 쓴다.

## 발행본 필수 구성 (누락 시 미완성)

- [ ] 제목 (`#`)
- [ ] 메타 설명 (≤160자, 인용/강조 블록)
- [ ] 본문 (도입·본문·결론)
- [ ] 출처 섹션 (본문 인용과 일대일)

## 산출 직전 자기 점검

- [ ] 교정 완료(맞춤법·문법·일관성).
- [ ] 사실 정합 검증 통과(허위 인용·dead 출처 없음).
- [ ] 메타 설명 ≤160자.
- [ ] 발행본 4대 구성요소 모두 존재.
- [ ] 수정 내역을 `04_edit_notes.md`에 기록(반려 있었으면 사유 포함).
