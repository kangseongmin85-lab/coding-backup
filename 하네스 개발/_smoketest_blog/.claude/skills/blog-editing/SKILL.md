# Blog Editing — 교정·검증·발행본 확정

초안을 **발행 가능한 글**로 만드는 마지막 게이트다. 단순 교정을 넘어 사실 정합·구조·SEO 메타를 점검하는 **생성-검증 게이트** 역할을 한다. 기준에 미달하면 작가에게 1회 반려한다 — 게이트가 통과시킨 글이 곧 사용자에게 가는 최종본이므로 책임이 크다.

## 입출력 (경계면 — 정확히 지킬 것)

- **입력:** `_workspace/03_draft.md` (blog-writer 산출물). 필요 시 `_workspace/02_research_outline.md`를 참조해 인용 출처가 실재하는지 대조한다.
- **출력 2개:**
  - `_workspace/05_final_blog_post.md` — 발행본: **제목 + 메타 설명(≤160자) + 본문 + 출처** 섹션을 모두 포함.
  - `_workspace/04_edit_notes.md` — 수정 내역과 반려가 있었다면 반려 사유.
- 두 파일명·경로를 글자 그대로 지킨다. `05_final_blog_post.md`는 오케스트레이터가 최종 보고에 쓰는 산출물이다.

## 작업 순서

1. **교정.** 맞춤법·문법·일관성(용어·표기·인칭·시제)을 잡는다. 세부 항목은 `references/editing-checklist.md`.

2. **구조·가독성 점검.** 도입-본문-결론이 갖춰졌는지, 문단 길이·소제목·논리 흐름이 적절한지 본다. 제목이 본문 내용과 정합하는지(낚시 여부) 확인한다.

3. **사실 정합 검증 (핵심 게이트).** 본문의 모든 `[출처 N]` 인용이 `02_research_outline.md`의 출처 목록에 실재하는지, 주장과 출처가 맞물리는지 대조한다. **허위 인용·dead 출처·출처 없는 단정**은 반려 사유다. `[출처 미검증]` 항목은 그대로 두되 발행본에서 단정 표현을 완화한다.

4. **반려 판단.** 반려 기준(`references/editing-checklist.md`)에 해당하면, **편집을 강행하지 말고** blog-writer에게 사유를 적어 SendMessage로 반려한다. 반려는 **최대 1회**. 수정 초안을 회신받으면 1~3을 재수행한다. 1회 후에도 미달이면 가용한 부분으로 발행하되 한계를 `04_edit_notes.md`와 발행본 상단에 명시한다.

5. **SEO 메타 생성.** 제목을 다듬고(키워드·길이), **메타 설명을 160자 이내**로 작성한다 — 검색 결과에 노출될 요약이다.

6. **발행본 확정.** 교정된 본문에 메타 설명을 얹어 `05_final_blog_post.md`로 저장하고, 수정 내역(+반려 사유 있으면)을 `04_edit_notes.md`로 저장한다. 오케스트레이터에게 최종본 확정을 통지한다.

## 산출물 구조

`05_final_blog_post.md`:
```
# {제목}

> **메타 설명:** {≤160자 검색 요약}

{교정된 본문 — 도입·본문·결론}

## 출처
- [출처 N] 제목 — URL — 매체
```

`04_edit_notes.md`:
```
# 편집 노트

## 수정 내역
- {무엇을 왜 고쳤는지}

## 반려 (있었던 경우)
- 반려 사유 / 회차 / 작가 회신 반영 여부

## 한계 (해당 시)
- 미검증 출처, 미해결 미달 항목
```

## 후속 작업 (재교정·메타 보강·발행본 업데이트)

이미 `05_final_blog_post.md`가 있고 보완 요청을 받으면, **전체 재편집 아님 — 요청 범위만**.

- "메타 설명 다시 / 제목 바꿔" → 메타·제목만 수정, 본문 보존.
- "재교정 / 다시 다듬어" → 교정만 재수행.
- 작가가 갱신한 `03_draft.md`가 들어오면 변경분 중심으로 다시 게이트를 통과시킨다.
- 수정 사항은 `04_edit_notes.md`에 append 한다(이력 보존).

## 팀 통신

- **발신:** blog-writer에게 재작성/수정 반려(사유 포함, 최대 1회). blog-researcher에게 사실 출처 보강 요청. 오케스트레이터에게 최종본 확정 통지.
- **수신:** blog-writer의 "수정된 초안 회신" → 게이트 재수행.

## 상세 기준

교정 항목, 사실 정합 검증법, 반려 기준, 메타 설명 작성법의 세부는 `references/editing-checklist.md`를 읽는다.
