# 리서치 체크리스트 & 표준

blog-research가 `02_research_outline.md`를 산출하기 전에 적용하는 기준.

## 출처 신뢰도 등급

근거의 출처를 다음 등급으로 평가하고, 가능하면 높은 등급을 우선 인용한다.

| 등급 | 예시 | 사용 |
|------|------|------|
| A (1차/권위) | 공식 통계청, 정부·국제기구 보고서, 동료심사 논문, 1차 데이터 | 통계·핵심 주장에 우선 |
| B (신뢰 매체) | 주요 언론, 업계 표준 기관, 공식 제품 문서 | 일반 사실·맥락 |
| C (보조) | 평판 있는 블로그·해설 기사 | 관점·예시 보강용. 단독 근거로는 약함 |
| 미검증 | 모델 지식만으로 작성(WebSearch 불가) | `[출처 미검증]` 명시 필수 |

상충하는 출처가 있으면 한쪽을 버리지 말고 **양쪽을 병기**하고 차이를 한 줄로 적는다 — 편집자가 판단할 수 있게 한다.

## 최소 출처 수

- 글 전체: 최소 3개의 독립 출처. 800단어 초과 시 섹션당 최소 1개 권장.
- 수치·통계 주장: 반드시 A 또는 B 등급 출처 1개 이상.
- 한 출처에 글 전체를 의존하지 않는다(단일 출처 의존 = 편향 위험).

## 출처 표기 형식

`[출처 N] 제목 — URL — 게시일/매체`

- N은 리서치 노트 본문의 `[출처 N]`과 일대일 대응.
- URL이 없으면(모델 지식) `[출처 미검증]`로 대체하고 N을 부여하지 않는다.
- 게시일을 알면 적는다 — 시의성 판단에 쓰인다(오래된 통계는 작가가 갱신 여부 판단).

## 개요 표준 구조

작가가 곧바로 초안을 쓸 수 있도록 다음을 모두 채운다.

1. **제목 후보 2~3개** — 키워드를 포함하고 클릭 유도가 되되 과장(낚시)은 피한다.
2. **도입** — 훅(문제·질문·통계) + 글이 다룰 범위 한 줄.
3. **본문 3~5섹션** — 각 섹션에 소제목 + 다룰 핵심 + **사용할 출처 매핑**. 섹션은 논리 순서(문제→원인→해법, 또는 시간/중요도 순)로 배열.
4. **결론** — 요약 + 독자 행동 제안 또는 마무리 메시지.

목표 분량에 맞춰 섹션 수를 조절한다: 800단어≈본문 3섹션, 1200단어≈4~5섹션.

## 산출 직전 자기 점검

- [ ] 전제(주제·키워드·독자·톤·분량·가정)가 상단에 명시되었다.
- [ ] 리서치 노트의 모든 사실에 `[출처 N]` 또는 `[출처 미검증]`이 붙었다.
- [ ] 출처 목록의 N이 본문 인용과 일대일 일치한다(dead 인용 없음).
- [ ] 독립 출처 ≥3, 통계 주장에 A/B 등급 출처가 있다.
- [ ] 개요의 모든 본문 섹션에 사용 출처가 매핑되었다.
- [ ] 상충 출처는 병기되었다.
