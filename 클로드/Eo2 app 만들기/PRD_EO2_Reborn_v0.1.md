## 1. 배경 (Background)

Electric Objects EO2는 2017년 출시된 23인치 디지털 아트 프레임으로, Wi-Fi를 통해 큐레이션된 디지털 아트를 슬라이드쇼처럼 표시하는 제품이었다. 2018년 Giphy에 인수된 후 서비스가 종료되어, 현재 EO2는 죽은 클라우드 서버를 끝없이 찾으며 "Internet connecting" 화면에 멈춰있는 사실상의 벽돌 상태다.

**그러나** 2026년 4월 30일, ADB 사이드로딩으로 spalt/EO1 대체 앱을 설치하고 원본 Electric Objects 앱을 비활성화하여 **하드웨어를 부활시키는 데 성공**했다. 이제 EO2는 어떤 Android 앱이든 디폴트 홈으로 띄울 수 있는 자유 상태에 있다.

본 프로젝트는 이 자유 상태를 활용해, EO2를 **가족용 멀티미디어 정보 디스플레이**로 재탄생시키는 자체 웹앱을 구축한다.

---

## 2. 문제 정의 (Problem Statement)

> 사용자(사장님 + 배우자)는 멀쩡한 EO2 하드웨어를 활용해, 폰 사진첩의 사진/GIF를 손쉽게 거실 디스플레이에 띄우고, 동시에 시계·날씨 같은 일상 정보를 한 화면에서 보고 싶다. 하지만 기존의 spalt/EO1과 michael/EO1 같은 대체 앱은 Flickr나 Immich 등 외부 서비스 의존도가 높아, 사용자 시나리오(폰 → 즉시 EO2)와 맞지 않는다.

## 3. 목표 (Goals) & 비목표 (Non-Goals)

### Goals
1. 7년 단종된 EO2를 일상에서 매일 쓰는 디지털 액자 + 정보 디스플레이로 부활시킨다
2. 폰에서 사진 업로드 → EO2 표시까지 **1분 이내** 완료한다
3. 시계 + 사진 + 날씨가 한 화면에서 자연스럽게 공존하는 메인 화면을 만든다
4. **100% 무료 운영** — 호스팅비, 도메인비, API 비용 모두 0원
5. 가로/세로 마운트 모두 지원 (사장님이 마음대로 바꿀 수 있게)
6. 코딩 모르는 사용자도 일상 운영(사진 업로드, 비밀번호 변경) 가능

### Non-Goals
- 터치 기반 인터랙션 (EO2는 비-터치 디스플레이)
- 음성 명령 / Alexa·Google Home 연동 (V1 범위 외)
- AI 생성 아트 (DALL-E 등 유료라서 V1 제외)
- 동영상 스트리밍 서비스 (Netflix·유튜브 등)
- 실시간 영상 통화 / 화상회의

## 4. 사용자 (Target Users)

### Primary Users — 사진 업로더 (2~3명)
- **운영자**: 사장님 (제약회사 PM, 프로젝트 owner, 비밀번호 관리)
- **공유자**: 배우자 또는 가까운 가족 1~2명 (사진 업로드 권한)

### Passive Users — 보는 사람
- 거실/공간을 같이 쓰는 가족 전체 (보기만 함)
- 가끔 방문하는 손님

## 5. 핵심 사용 시나리오 (User Stories)

| ID | 시나리오 |
|----|---------|
| **US-1** | 가족 구성원으로서, 폰에서 EO2 웹주소를 북마크해두고, 평소처럼 갤러리에서 사진을 선택해 업로드 버튼 누르면 1분 내로 EO2에 새 사진이 뜬다 |
| **US-2** | 재미있는 GIF나 짧은 영상을 EO2에 띄워 거실 분위기를 만든다 |
| **US-3** | EO2를 거실 시계로도 쓴다. 사진 위에 디지털 시계가 오버레이 되어 시간을 한눈에 보면서 사진도 즐긴다 |
| **US-4** | 아침에 거실에 들어와서 EO2 화면 한 번에 오늘 날씨를 확인한다 |
| **US-5** | EO2 화면에 표시되는 QR 코드를 폰으로 스캔하면 바로 업로드 페이지가 열린다 (V2) |
| **US-6** | 가족이 아닌 사람이 우연히 URL을 알게 돼도 비밀번호 없으면 사진 업로드는 못 한다 |

## 6. 기능 요구사항 (Functional Requirements)

### V1 (MVP) — 4~6주 목표

| ID | 기능 | 설명 |
|----|------|------|
| **F1** | 사진 슬라이드쇼 | 업로드된 사진을 자동 슬라이드쇼로 표시. **디폴트 1분 간격** (10초~1시간 조정 가능), 셔플 ON/OFF, 자동 리사이징 |
| **F2** | 사진/GIF 업로드 웹페이지 | 가족 비밀번호 로그인 → 폰 갤러리에서 다중 선택 → 업로드. JPG/PNG/GIF/MP4(짧은 것) 지원. 업로드 진행률 표시 |
| **F3** | 실시간 시계 위젯 | **다양한 디자인 테마 (미니멀 디지털 / 플립시계 / 아날로그 / 네온 / 클래식 등 토글 가능)**. 24시간/12시간 포맷 선택. **두 가지 표시 모드 토글**: ① 사진 위 오버레이 (좌하/우하 위치 선택), ② 시계 전용 모드 (사진 없이 시계만) |
| **F4** | 날씨 위젯 | **경기도 용인시 상현2동** 기반. 현재 온도+날씨 아이콘+미세먼지(PM2.5). 1시간마다 자동 업데이트. 우상단 작은 위젯 |
| **F5** | 가로/세로 자동 지원 | EO2 디바이스 방향 감지하여 콘텐츠 레이아웃 자동 조정 |
| **F6** | 가족 공유 인증 | 메인 비밀번호 1개 (가족 공통). 사장님이 변경 권한. 게스트 가족도 동일 비밀번호로 업로드. **비밀번호는 셋업 단계에서 결정** |

### V2 — V1 출시 후 1~2개월

| ID | 기능 | 설명 |
|----|------|------|
| **F7** | QR 코드 업로드 | EO2 화면 일정 시간마다 QR 코드 표시 → 폰 스캔 → 업로드 페이지로 즉시 진입 |
| **F8** | 카카오톡 봇 업로드 | 카톡 봇으로 사진 보내면 자동 업로드 (등록된 카톡 ID만) |
| **F9** | 명화 자동 큐레이션 | Met Museum, Rijksmuseum, Art Institute Chicago API 연동. 매일/매주 새 명화 추가 |
| **F10** | 사진 앨범 분리 | 폴더/태그별 슬라이드쇼 (예: "여행", "가족", "일상"). 시간대별 자동 큐레이션 |

### V3 — 향후 검토 (Out of Initial Scope)

> ❌ **주식 위젯은 본 프로젝트에서 명시적으로 제외** (사용자 결정 — 2026-04-30)

| ID | 기능 | 설명 | 상태 |
|----|------|------|------|
| ~~F11~~ | ~~주식 위젯~~ | ~~한국/해외 주식~~ | ❌ **제외 확정** |
| **F12** | 캘린더 연동 | Google Calendar 오늘 일정 표시 | 향후 검토 |
| **F13** | "오늘의 추억" | N년 전 같은 날 사진 자동 큐레이션 | 향후 검토 |

## 7. 비기능 요구사항 (Non-Functional Requirements)

### 성능 (Performance)
- EO2 첫 화면 로딩 < 5초
- 사진 업로드 → EO2 표시 < 1분
- 가족 사용량 (3명, 일 평균 5장 업로드) 무리 없는 동작

### 비용 (Cost) — 핵심 제약
- 호스팅: **0원** (Cloudflare Pages 또는 Vercel)
- 사진 저장: **0원** (Cloudflare R2 10GB 무료 티어)
- DB: **0원** (Firebase Firestore 무료 티어)
- API: **0원** (모두 무료 티어)
- 도메인: **0원 — 무료 서브도메인 사용 확정** (예: `eo2-vamos.pages.dev`)
- **월 총 비용: 0원 (절대 유지)**

> 💡 **비용 정책 (사용자 결정)**: 어떤 상황에서도 유료로 전환하지 않음. 무료 한도 초과 위험 시 자동 압축/오래된 사진 정리 등으로 한도 내 유지.

### 보안 (Security)
- 가족 비밀번호 인증 + 세션 토큰
- HTTPS only
- 외부에서 EO2 디스플레이 화면 접근 시 인증 필요
- 사진 URL은 추측 어려운 hash 사용

### 안정성 (Reliability)
- 인터넷 끊겨도 캐시된 사진 표시 (graceful degradation)
- 자동 재연결 로직
- EO2 24/7 켜진 상태 가정

### 호환성 (Compatibility)
- 사용자 폰: iOS Safari, Android Chrome (모바일 웹브라우저)
- EO2 내장 Chromium: 구버전 호환 모드로 개발

## 8. 기술 아키텍처 (Technical Architecture)

```
┌──────────────┐                         ┌────────────────────┐
│ 가족 폰      │  HTTPS  →               │ Cloudflare Pages   │
│ (iOS/Android)│  업로드                 │ (웹앱 호스팅)       │
│              │←──────                  │                    │
│ - 모바일웹   │                         │  ┌──────────────┐  │
└──────────────┘                         │  │ 업로드 페이지 │  │
                                         │  │ 관리 페이지   │  │
                                         │  │ 디스플레이    │  │
                                         │  └──────────────┘  │
                                         └─────────┬──────────┘
                                                   │
                  ┌────────────────────────────────┼─────────────────────┐
                  │                                │                     │
                  ▼                                ▼                     ▼
        ┌──────────────────┐          ┌──────────────────┐    ┌────────────────┐
        │ Cloudflare R2    │          │ Firebase         │    │ 외부 API        │
        │ (사진 저장)      │          │ Firestore        │    │ - 날씨          │
        │                  │          │ (메타데이터, 인증) │    │ - 명화 (V2)    │
        └──────────────────┘          └──────────────────┘    │ - 주식 (V3)    │
                                                              └────────────────┘

┌──────────────┐
│ EO2 Chromium │  ← URL 접속 → Cloudflare Pages 디스플레이 모드 페이지
│ (디스플레이) │
└──────────────┘
```

### 기술 스택
- **프론트엔드**: HTML / CSS / JavaScript (Vanilla 또는 경량 React/Preact)
- **호스팅**: Cloudflare Pages (백업: Vercel)
- **사진 저장소**: Cloudflare R2 (egress 무료가 결정적)
- **데이터베이스**: Firebase Firestore (메타데이터, 가족 비밀번호)
- **인증**: 단순 비밀번호 + JWT 세션
- **외부 API**:
  - 날씨: OpenWeatherMap (1,000 호출/일 무료) — 경기도 용인시 좌표 기반
  - 미세먼지: 한국환경공단 에어코리아 API (무료)
  - 명화 (V2): Met Museum, Rijksmuseum, Art Institute Chicago (무제한 무료)

## 10. 리스크 & 가정 (Risks & Assumptions)

### Risks

| 리스크 | 영향 | 대응 |
|--------|------|------|
| EO2 내장 Chromium이 너무 구식이라 최신 웹 표준 못 씀 | 중 | 호환 모드로 개발, polyfill 사용 |
| Cloudflare 무료 정책 변경 | 저 | Vercel 백업 호스팅 준비 |
| EO2 Wi-Fi 연결 끊김 | 중 | 캐시된 사진 표시, 자동 재연결 |
| 사진 용량이 10GB 초과 | 저 | 자동 압축, 오래된 사진 자동 정리 |

### Assumptions
- 사장님 집에 안정적 Wi-Fi 있음
- EO2 24/7 전원 연결
- 가족 구성원 폰에 모바일 웹 사용 가능
- 사장님은 일상 운영(사진 업로드)만 하고 큰 변경은 Claude와 협업

**디바이스**: EO2 (시리얼 20061942, MAC F8:02:78:50:29:EF)
