# Review SRS — 간격 반복 복습

암기한 문장이 장기 기억으로 가도록 Leitner 박스 방식으로 복습을 관리한다.

## 박스와 간격

| box | 다음 복습까지 간격 |
|-----|------------------|
| 1 | 1일 |
| 2 | 2일 |
| 3 | 4일 |
| 4 | 7일 |
| 5 | 14일 (이후 14일 유지) |

## 갱신 규칙

복습(또는 받아쓰기) 결과에 따라 `sentences.json`의 `srs` 필드를 갱신한다:

- **성공**: `box` +1 (최대 5), `next_review` = 오늘 + 새 box의 간격, `last_result` = "pass"
- **실패**: `box` = 1, `next_review` = 내일, `last_result` = "fail"
- 성공 기준: 받아쓰기 정답률 80% 이상, 또는 한→영 변환에서 핵심 패턴을 살려 의미가 통하는 문장을 만들면 성공.

받아쓰기 세션(listening-drill)도 복습으로 인정한다 — 같은 문장을 이중으로 복습시키지 않는다.

## 복습 세션 진행

1. 복습 큐 산출: `srs.next_review <= 오늘`인 문장. 큐가 비면 "오늘 복습 없음"과 다음 복습 날짜를 알린다.
2. 문장당 복습 방식을 번갈아 사용한다:
   - **듣기 방식** (기본, 사용자 약점): 오디오 재생 → 받아쓰기 또는 "뜻을 한국어로 말하기". listening-drill 절차 간소판 — 텍스트 먼저 보여주지 않기 철칙 동일.
   - **말하기 방식**: 한국어 뜻 제시 → 사용자가 영어로 입력 → 패턴이 살았는지 평가. 최종 목표(유창하게 말하기)와 직결.
3. 결과를 위 갱신 규칙대로 기록하고, `data/sessions/{YYYY-MM-DD}_review.md`에 로그를 남긴다. `data/study_log.json`에도 세션 엔트리(mode: review, attempted/passed)를 추가한다 (`study-record` 스킬 규칙).

## 큐 관리

- 복습 큐가 15개를 넘으면 box 낮은 순(약한 문장 우선)으로 10개만 진행하고 나머지는 내일로 미룬다. 한 번에 몰아서 하면 효과가 떨어진다.
- 5회 연속 실패한 문장은 사용자에게 알린다: 문장이 너무 길거나 안 쓰는 표현일 수 있으니 분할/교체를 제안한다.
