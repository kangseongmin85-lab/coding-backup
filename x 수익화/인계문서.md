## 1. 한 줄 요약

실시간 이슈 → 블로그·X 콘텐츠 초안 → 카드 이미지 → 노션 저장 → 텔레그램 알림을
**GitHub Actions에서 30분마다 무인 자동 실행**하는 파이프라인. 현재 가동 중이며,
Anthropic API 크레딧만 충전하면 완전체가 됨.

## 2. 저장소

```bash
git clone https://github.com/kangseongmin85-lab/issue2content.git
cd issue2content
```

- 공개 저장소 (Actions 무제한 무료 목적). 비밀값은 전부 GitHub Secrets에 있고 코드에는 없음.
- 워크플로: `.github/workflows/daily.yml` — cron `*/30 * * * *` (30분 간격, 24시간)

## 6. 남은 이슈 (우선순위 순)

### (A) Anthropic API 크레딧 0원 — 최우선

```
400 invalid_request_error: Your credit balance is too low to access the Anthropic API.
```

→ https://console.anthropic.com/settings/billing 에서 충전.
충전 전까지는 `writer.py`의 폴백이 작동해 **템플릿 모드**(헤드라인 정리 수준)로만 저장됨.
현재 노션 페이지 제목이 전부 "오늘 화제: X — 헤드라인 정리"인 이유가 이것.

### (B) 쓰레기 키워드가 이슈로 선정됨

노션에 `[2026-08-19] com`, `[2026-08-18] kr` 같은 페이지가 생성됨.
원인: RSS 제목 끝의 출처 표기(`- v.daum.net`)에서 `com`, `kr`, `net` 등이 토큰으로 잡힘.

수정 위치: `collector.py`의 `_tokens()` 또는 `STOPWORDS`.

제안 수정:

```python
TLD_LIKE = {"com", "kr", "net", "co", "org", "www", "https", "http", "news"}

def _tokens(title: str):
    title = re.sub(r"\s*-\s*[\w.]+\.(com|kr|net|co\.kr|org)\s*$", "", title)  # 꼬리 출처 제거
    words = re.findall(r"[가-힣A-Za-z0-9]{2,}", title)
    return [w for w in words if w not in STOPWORDS and w.lower() not in TLD_LIKE]
```

추가로 한글 2자 미만/영문 단독 토큰을 걸러도 좋음.

### (C) 일부 회차가 15분씩 걸리다 경고로 끝남 (#26, #27)

Playwright 설치 단계 지연 추정. 캐시가 미스나면 오래 걸림.
`daily.yml`의 `actions/cache@v4` 키를 안정화하거나 `playwright install chromium`만(--with-deps 제외) 시도해볼 것.

### (D) Node.js 20 deprecation 경고

`actions/checkout@v4` 등이 Node 24로 강제 실행 중. 동작엔 문제 없음. 나중에 v5 계열로 올리면 됨.

## 7. 보안 — 반드시 처리

세션 중 채팅창에 붙여넣어진 값이라 **재발급 권장**:

- Notion 통합 토큰 (Notion 개발자 페이지에서 Regenerate)
- Anthropic API 키 (콘솔에서 삭제 후 재발급)
- 텔레그램 봇 토큰 (@BotFather → `/revoke`)

재발급 후 GitHub Secrets의 해당 값만 교체하면 됨.

## 9. Cowork 쪽 자산 (참고)

같은 파이프라인의 고품질 버전이 Cowork 스킬로도 존재함:

- `issue-to-content` — 원문까지 읽고 수치 교차검증, 저작권 15항목 체크, 3회 린트
- `natural-writing-review` — AI스러움 제거 3회 린트 (서브에이전트 각 회차 독립 실행)

깊게 파야 하는 이슈는 Cowork에서, 평시 자동 운영은 이 프로그램으로 쓰는 투트랙 설계.
